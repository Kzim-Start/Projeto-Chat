# Crimson Mage — instruções de continuidade

1. Leia `PROGRESS.md`, as seções relevantes de `MASTER_PROMPT.md` e o código antes de modificar o projeto.
2. Respeite o intervalo de seções ou bloco explicitamente autorizado pelo usuário. Seções do documento e blocos de implementação são numerações diferentes.
3. Use Godot 4.x e GDScript. Não transforme este projeto em um jogo web ou troque a engine.
4. Implemente, conecte, execute e teste a etapa atual. Não marque PASS sem executar a verificação correspondente.
5. Use chaves de tradução para textos de interface e Resources para dados. Evite Autoloads sem uma necessidade atual e scripts vazios para funcionalidades futuras.
6. Nunca misture Run Coins e Saved Coins. Fechar o aplicativo não significa abandonar uma run. A transferência após vitória deve ocorrer exatamente uma vez quando esse sistema for implementado.
7. Preserve trabalho existente. Faça commits pequenos por etapa estável e atualize `PROGRESS.md` antes de encerrar.
8. Arte provisória pode ser identificada como tal; funcionalidades do bloco atual não podem ser botões falsos ou TODOs.
9. Registre separadamente testes Linux, Windows, Android e iOS. Não trate execução headless como teste visual ou teste em aparelho.
10. Pare ao concluir o conjunto autorizado e descreva o próximo passo.
